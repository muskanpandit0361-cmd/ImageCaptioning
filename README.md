# 🔬 VisionCaption AI — Intelligent Image Description Generator

A production-quality, AI-powered web application that generates natural-language
descriptions of uploaded images using the **Salesforce BLIP** vision-language model.

> **No API key required.** All inference runs locally on your machine using
> pretrained model weights downloaded from Hugging Face.

---

## ✨ Features

- **Real AI inference** — descriptions are generated by the BLIP model, not
  hardcoded or rule-based.
- **Two description modes** — concise Standard Caption or longer Detailed
  Description.
- **Configurable generation** — adjust beam count, max tokens, and other
  parameters from the sidebar.
- **Upload validation** — file type, size, dimensions, and content checks
  with clear error messages.
- **Copy & download** — one-click copy and `.txt` download of generated
  captions with metadata.
- **Evaluation pipeline** — BLEU-1, BLEU-4, and ROUGE-L against human
  reference captions.
- **Modern UI** — polished Streamlit interface with custom CSS, responsive
  layout, and session-state persistence.
- **Fully tested** — pytest suite with mocked inference (no model download
  needed for CI).

## 🚀 Installation & Setup

### Prerequisites

- **Python 3.10 or 3.11** installed and available on `PATH`.
- **Git** for version control.
- **Internet access** for the initial model download (~990 MB, cached afterwards).
- At least **4 GB free RAM** for CPU inference (8 GB recommended).

### Windows (PowerShell)

```powershell
# 1. Clone or navigate to the project
cd C:\Users\muska\OneDrive\Desktop\GenAI\VisionCaption-AI

# 2. Create a virtual environment
python -m venv venv

# 3. Activate it
.\venv\Scripts\Activate.ps1

# 4. Upgrade pip
python -m pip install --upgrade pip

# 5. Install PyTorch (CPU-only — fastest install)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 5a. OR install PyTorch with CUDA 11.8 support (if you have an NVIDIA GPU)
# pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

# 5b. OR install PyTorch with CUDA 12.1 support
# pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 6. Install remaining dependencies
pip install -r requirements.txt

# 7. Start the application
streamlit run app.py
```

### Linux / macOS

```bash
cd VisionCaption-AI

python3 -m venv venv
source venv/bin/activate

pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

streamlit run app.py
```

The application will open at **http://localhost:8501**.

### First-run behaviour

On first launch the BLIP model weights (~990 MB) are downloaded from
Hugging Face Hub and cached in `~/.cache/huggingface/`.  Subsequent starts
reuse the cache and are much faster.

## ☁️ Deployment (Streamlit Community Cloud)

### Requirements

1. Push the project to a **public GitHub repository**.
2. Ensure `requirements.txt` is at the repository root.
3. Add a `packages.txt` file if any system-level packages are needed
   (typically not required for this project).

### Steps

1. Go to [share.streamlit.io](https://share.streamlit.io/).
2. Click **New app** → select your repository, branch, and `app.py`.
3. Click **Deploy**.

### Considerations

| Concern              | Detail                                                    |
|----------------------|-----------------------------------------------------------|
| **Memory**           | Free tier has ~1 GB RAM; BLIP Base loads at ~1 GB.  The   |
|                      | app may hit memory limits under load.                      |
| **Cold start**       | First request after idle downloads the model — can take    |
|                      | 60–120 seconds.                                            |
| **Model cache**      | Streamlit Cloud may evict the HF cache between sessions.   |
| **Upload limit**     | Streamlit Cloud enforces its own upload limit (200 MB).    |
| **CPU only**         | No GPU is available on the free tier.                      |

### Alternative hosting

If Streamlit Community Cloud cannot reliably serve the model:

- **Hugging Face Spaces** — free tier with 2 GB RAM and optional GPU.
- **Google Colab** — run `!streamlit run app.py &` with a localtunnel.
- **Railway / Render** — paid tiers with more memory.

## ⚠️ Limitations

- BLIP Base may produce inaccurate, incomplete, or hallucinated descriptions.
- Detailed mode uses a text prompt to encourage longer output but BLIP Base
  is not an instruction-following model — results may still be brief.
- CPU inference takes 2–10 seconds per image depending on hardware.
- The model was trained on English-language data and may not describe
  culturally specific objects or scenes accurately.
- No user accounts, history, or persistent storage.
