# Evaluation Module

## Purpose

This module provides a reproducible evaluation pipeline for measuring the quality
of captions generated by VisionCaption AI against human-written reference captions.

## Metrics

| Metric   | What it measures | Range |
|----------|------------------|-------|
| BLEU-1   | Unigram precision between generated and reference captions | 0–1 |
| BLEU-4   | 4-gram precision (penalises short or repetitive outputs) | 0–1 |
| ROUGE-L  | Longest common subsequence F1 score | 0–1 |

Higher values indicate closer alignment with human reference captions.
These metrics measure lexical overlap; they do not guarantee semantic correctness.

## Setup

### 1. Obtain evaluation images

Download a small subset (e.g., 50–200 images) from one of:

- **Flickr8k** — [Kaggle mirror](https://www.kaggle.com/datasets/adityajn105/flickr8k)
- **MS COCO** — [cocodataset.org](https://cocodataset.org/#download)

Place the images in the `assets/` directory.

### 2. Prepare reference captions

Update `sample_references.json` with the actual image filenames and their
human-written reference captions from the dataset's annotation file.

Each entry maps a filename to a list of reference captions:

```json
{
    "COCO_val2014_000000012345.jpg": [
        "A cat sitting on a red couch.",
        "A tabby cat resting on a sofa."
    ]
}
```

### 3. Run the evaluation

```bash
python evaluation/evaluate.py \
    --images-dir assets \
    --references evaluation/sample_references.json \
    --output-dir outputs
```

### 4. Review results

- `outputs/evaluation_results.csv` — per-image metrics
- `outputs/evaluation_summary.json` — aggregate statistics

## Important Notes

- Do **not** present the sample placeholder entries as real evaluation data.
- The evaluation must be run with actual images and their official reference
  captions before reporting any quantitative results.
- BLEU and ROUGE measure lexical similarity, not factual accuracy.
